# Eigene Sprites

Hier liegen eigene Bilder, die die gezeichnete Grafik ersetzen oder neue Sprites hinzufügen:
`art-src/png/<Satz>/<Name>.png` mit genau dem Namen aus dem Export (`python3 tools/sprites/sprites.py export --all`).
Danach `python3 tools/sprites/sprites.py apply` oder alles im Browser: `python3 tools/sprites/sprites.py serve`.
Mehr in `docs/SPRITES.md` („Sprites als PNG“).
